# Intelliputer Connector — J2 1.000 mm

The baseline version of the passive 44-way (2 × 22) Intelliputer card-edge
adapter. All 44 J2 plated through-holes use a **1.000 mm (0.0394 in)** drill.

The released revision 1.1 fabrication package is in
[`../../manufacturing/intelliputer-connector-j2-1.000mm/`](../../manufacturing/intelliputer-connector-j2-1.000mm/).
