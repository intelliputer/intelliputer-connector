# Intelliputer Connector — J2 0.889 mm

Variant of the passive 44-way (2 × 22) Intelliputer card-edge adapter with
all 44 J2 plated through-holes set to **0.889 mm (0.035 in)**.

This matches the plated drill size of the M6x09-II-SBC's H2 expansion header
and is intended for the tighter-fit wire-wrap-terminal interconnection option.
